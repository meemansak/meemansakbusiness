# Meemansak Bharti

Personal site for business consulting, practical AI, automation, and web and app development.

[Live site](https://meemansak.github.io/meemansakbusiness/)

GitHub Pages publishes the root of the main branch. Edit the copy, business links, and inquiry address in `index.html`. The inquiry form prepares an email draft in the visitor’s mail app. Set session fees in `site.js`.

The portrait in the About section is from Wedditors.

## Continue on another computer

Clone this repository once on each computer. On a clean checkout of `main`, run `git pull --ff-only origin main`, then open this folder in Codex and ask it to read [HANDOFF.md](HANDOFF.md). It records the current site, checks already run, and the next step. [AGENTS.md](AGENTS.md) records how to work on the site and deploy it.

Keep each handoff update in the same commit as the related website changes. Push completed work to GitHub before switching computers.
